
# Project 21: CloudWatch Monitoring Dashboard

## Goal
Visualize virtual machine performance using Amazon CloudWatch.

## Technologies Used
- AWS CloudWatch
- AWS CLI
- Ubuntu Linux
- JSON

## Metrics Monitored
1. CPU Utilization
2. Memory Utilization
3. Disk Utilization

## Monitoring Results

| Metric | Observed Value |
|---|---:|
| CPU Utilization | 5.8% |
| Memory Utilization | 11.30% |
| Disk Utilization | 77% |

## Dashboard
Dashboard Name: Project21-CloudWatch-Dashboard

AWS Region: ap-south-1 (Mumbai)

## Implementation
1. Collected VM performance metrics.
2. Published custom metrics to CloudWatch.
3. Created a CloudWatch dashboard using AWS CLI.
4. Configured three metric widgets.
5. Verified dashboard in AWS Console.
